# Битва легенд — план разработки

Принцип: каждый этап заканчивается сборкой для Windows, которую автор скачивает и проверяет.
Все механики и спорные решения согласуются через вопросник.

**Роли.** Автор генерирует спрайты по ТЗ, играет в сборки и даёт отзывы.
Claude пишет код и документы, обрабатывает спрайты и собирает игру.

## Этап 1. Ядро боя на временной графике
Цель — проверить управление и ощущение боя до того, как появятся спрайты.
- [ ] Проект Godot 4, сборка `.exe` для Windows
- [ ] Детерминированный игровой цикл (60 тиков в секунду, целочисленная физика)
- [ ] Ввод: геймпад (DualSense) и клавиатура, переназначение кнопок, буфер ввода
- [ ] Движение: ходьба, бег, отскок, прыжки, присед, разворот к сопернику
- [ ] 4 обычных удара стоя, в приседе и в прыжке, блок верхний и нижний
- [ ] Хитбоксы и хартбоксы по кадрам, урон, hitstun и blockstun
- [ ] Hitstop, тряска камеры, отбрасывание
- [ ] Раунды, таймер, полоски здоровья, экран победы
- [ ] Бойцы — цветные фигуры с разными размерами и скоростью
- [ ] Автотест детерминизма (основа будущего онлайна)

**Автор:** проверяет управление с геймпадом, пишет отзывы.
