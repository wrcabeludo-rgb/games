# Битва легенд — план разработки

**Принцип.** Каждый подэтап заканчивается сборкой для Windows и коротким чек-листом
«что проверить». В сборке появляется немного нового — ошибку легко найти, отзыв короткий.
Очень маленькие подэтапы можно объединять в одну сборку (с предупреждением).
Все механики и спорные решения согласуются через вопросник.

**Роли.** Автор генерирует спрайты по ТЗ, играет в сборки и даёт отзывы.
Claude пишет код и документы, обрабатывает спрайты и собирает игру.
