# Лента — арена босса (`feed`)

Цифровая пустота, где рассыпаются легенды. Слева — обломки знакомых миров (купола, храм, пирамида) распадаются на пиксели и улетают вверх. Справа — бесконечная стена из светящихся вертикальных экранов. Пол — тёмное стекло со светящейся сеткой. Палитра: тёмно-синий, циан #33C2F2, белый, красный #E8333A (значки уведомлений). Никакого фиолетового и розового — фон вырезается по пурпуру.

Как делать: сначала небо (1), потом прикладывайте его референсом ко всем остальным. Полосы — тремя панелями слева направо; для стыковки прикладывайте и предыдущую панель. Формат 21:9, максимальное разрешение. Имена файлов — как в заголовках; присылайте с подписью арены, обработка: `python3 tools/process_arena_art.py <папка> feed`.
