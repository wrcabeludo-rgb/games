# «Битва легенд» — контекст проекта для Claude

Документ для загрузки в проект Claude (claude.ai → Projects → Project knowledge). Обновлять при каждой крупной
вехе. Полные правила и история — `CLAUDE.md` в корне репозитория (`wrcabeludo-rgb/games`).

## 1. Что это
2D-файтинг на **Godot 4.4.1** для Windows, управление с геймпада DualSense. Код — в `bitva-legend/game/`.
Общение — **по-русски**. Владелец генерирует картинки (Gemini/Imagen) и видео (**Veo 3**) по промптам Claude и
присылает их; Claude пишет код, обрабатывает арт, пишет промпты, выпускает сборки.

**Лор.** Десятилетний Саша засыпает с книгой «Легенды народов мира»; его затягивает в экран, где хозяин бесконечного
шоу **Скроллер** стравливает героев книги, подвешенных на нитях, как марионеток, в «кроссовер-ивентах».
Победа рвёт нити. Финал: Аватар (цифровой Саша), затем сам Скроллер. Тон — эпос с юмором; игра не ругает
телефоны, а напоминает дочитывать истории. **Лор без команды владельца не переписывать.**

**Бойцы.** Илья Муромец (борец с палицей), Дракула (дуэлянт и ассасин, когти и плащ), Кощей (база готова),
Геракл, Афина, Медуза, Сунь Укун, Анубис (заглушки), финал — Аватар и Скроллер (механики готовы, ждут арта).

## 2. Как работаем
- **Сначала опросник, потом промпт.** Перед каждым ударом/движением — варианты на выбор, рекомендация Claude
  первой, чтобы бойцы двигались по-разному. Если владелец просит промпт — сначала отдать промпт.
- **Промпт целиком одним блоком вместе с NEGATIVE PROMPT**, полный текст без «как раньше»; в чат и файлом.
- **Ничего не стирать с готовых анимаций без подтверждения владельца** (пыль, следы, части плаща).
- Каждая заметная правка — сборка и ссылка владельцу:
  https://github.com/wrcabeludo-rgb/games/releases/latest/download/BitvaLegend-windows.zip
  (собирает GitHub Actions при пуше в `main`; версия — `config/version` в `game/project.godot`).
- Схема ударов: лёгкий рукой — передней рукой; сильный рукой — задней/оружием; лёгкий ногой — передний толчок;
  сильный ногой — задней, маваши или уширо. Удары в прыжке: одна анимация на ЛР/СР и одна на ЛН/СН;
  удары ногой сидя — одна на ЛН/СН.

## 3. Пайплайн арта
- **Анимации — из видео Veo** (картинки не переставляют ноги). Стартовая картинка бойца на сплошном
  пурпурном #FF00FF, 1280×720, строгий вид сбоку лицом вправо, запас сверху/снизу; в промпте: «flat 2D character
  that can never rotate», «camera completely static, no zoom», «background perfectly flat #FF00FF». 2–3 движения
  в одном 10-секундном ролике, каждое начинается и кончается в стойке.
- Типичные беды Veo: приближает камеру (кадры выравниваем по размеру головы/линии земли), обрезает верх
  (стартовая картинка с запасом), разворачивает к зрителю, рисует пыль/следы, смешивает двух персонажей.
- Обработка: `tools/video_sheet.py` (лист кадров) → `tools/process_fighter_art.py <боец> <листы>`
  (настройки в `art_src/fighters/<боец>/sheets.json`) → `game/art/fighters/<боец>/`.
- **Парные сцены** (оба бойца в одном ролике): суперприёмы и броски для пары Илья–Дракула. Чтобы Veo не смешивал
  персонажей — **опорные кадры** картинками (ключевые позы), затем короткие ролики «от кадра к кадру».
- Эффекты (попадания, блок, укус, туман, мыши, волна, кратер) — картинки по 4 кадра в ряд на пурпуре.
- Арены: пока по одной картинке-заглушке на карту (21:9); Сад Гесперид — живая проба: небо роликом + слои.

## 4. Где мы сейчас (версия 3.17.39)
- **Илья**: почти всё из видео — стойка, ходьба, бег, отскок, удары стоя и апперкот, блок, урон, падение,
  приёмы (бросок палицы, удар оземь с волной, таран, мельница), суперприём «Удар с небес».
  Ждут роликов: удары рукой/ногой сидя, прыжок и удары в прыжке, подсечка палицей; опросник — блок и урон сидя.
- **Дракула**: всё ключевое из видео с новым лицом — стойка, шаг, бег, отскок, блок-кокон, все удары стоя/сидя/
  в прыжке, подсечка, сальто, стая мышей, туманный рывок, гипнотический взгляд, укус, суперприём «Кровавая луна».
  Старые: урон, падение, вставание, экран выбора.
- **Парные сцены Илья–Дракула** (броски обоих, суперприёмы обоих) — целиком из видео.
- Реакции на захваты (4 позы) у Ильи и Дракулы; хитбоксы подогнаны под рисунок (автотест дальности).
- 11 арен-заглушек; выбор арены на экране «ПРОТИВ» (влево/вправо); Сад Гесперид — живое небо.
- 20 наборов автотестов проходят.

## 5. Ближайшие задачи
1. Илья: удары сидя, прыжок/удары в прыжке, подсечка; опросник по блоку и урону сидя.
2. Дракула: урон, падение, вставание, экран выбора.
3. Кощей: спецприёмы и суперприём «Смерть в игле».
4. Остальные бойцы: модельные листы v2 (живые люди, не аниме) → видео.
5. Арены: разделить заглушки на слои, оживить.
6. Отложено: баланс, картинки истории с Сашей, Аватар и Скроллер.

## 6. Что умеет только Claude Code
Сборка, тесты, обработка видео и картинок, коммиты и релизы делаются в сессии **Claude Code** с этим
репозиторием (она сама читает `CLAUDE.md`). Чат-проект на claude.ai подходит для обсуждений, лора, опросников и
промптов: готовые промпты и решения потом передавать в сессию Claude Code (или записывать в `CLAUDE.md`).
