# Вводные для Claude: «Жизнь заново»

Текстовая терапевтическая игра-PWA (чистый JS, без сборки) в папке `zhizn-zanovo/`. Владелец тестирует на телефоне.
Общаемся по-русски. Замысел и механика — `docs/DESIGN.md`, структура — `README.md`.

- Проверка перед пушем: `node zhizn-zanovo/tools/sim.js 1000` (0 проблем) и прогон в Chromium (Playwright) на 390×844.
- Новые события: `Z.def([...])` в `js/data/ev_*.js`; частые события — только с вариантами `vars` (`ev_variety.js`);
  у детей и друзей род — всегда через `{K~пошёл|пошла}`; эффекты — мини-язык `Z.fx` (`engine.js`), шаблоны — `Z.t`.
  Новый файл добавить в `index.html` и в список `FILES` в `sw.js`.
- При выпуске поднять `Z.VERSION` (`engine.js`) и `CACHE` в `sw.js`. **В конце каждого ответа владельцу писать версию**
  («Версия 0.4.0»); в игре она видна внизу экрана.
- Варианты выбора, собираемые случайно, строятся от «зерна» карточки (`Z.view` → `Z.withSeed`) — иначе на экране
  одни варианты, а при нажатии другие. Тексты про детей/жену — только при их наличии (автотест это ловит).
- Память поступков: в `fx` выбора — `mem:ключ[:кто]`, тексты — `Z.MEM` (`world.js`); развилки карты судьбы — `Z.FORKS` (`story.js`).
- Студенческие события — флаг `uni: true` (только в институте: `Z.uni`); в армии доходит только `Z.ARMY_OK`; сезонные
  события — через `Z.inMonth`. Незнакомец выключен (`Z.STRANGER_ON = false`) по решению владельца.
- Тон (решение владельца, 0.7): тепло и ностальгия («Заря», This Is Us, «Мир, дружба, жвачка», Stardew Valley) + необратимые
  последствия (Detroit, Fahrenheit). Тексты — конкретная деталь, подтекст, короткие фразы, без «ты почувствовал грусть».
  Между главами — не итоги, а короткий текст (`ch_end`); карта судьбы — в меню и в финале.
- Механики «сердца» (`js/heart.js`, сцены — `js/data/ev_heart.js`): вещи `thing:ключ` (`Z.THINGS`, находятся через годы — `he_find`),
  ритуалы `rit:ключ` (`Z.RITUALS`, событие `ri`; два пропуска подряд — кончается навсегда), последний обычный день
  (сам запоминается по `@кто+` в выборе; после утраты — `he_last`), несказанное `unsaid:love:mom` / `said:mom` → письмо `he_letter`,
  звонок с таймером (`timer: 6` у события, вариант `late: true` — что будет, если не успел; кнопкой не показывается),
  строка из будущего (`ff:` у выбора — редко), культурные коды по годам `Z.code(s, 'ny'|'song'|'child'|'kitchen'|'tape')`.
- Перекрёстки (`ev_crossroads.js`, ★ на карте судьбы) — выбор с ценой: что-то приобретаешь, что-то теряешь, последствия через месяцы.
- Картинки — `art/<стиль>/stage.webp` (1200×800), список — `js/data/art.js`, исходники — `art_src/stage/`.
  Сцены (стиль линера, в любом возрасте) — `art/scenes/<ключ>.webp`, листы 3×3 из ChatGPT (`docs/ART_SHEETS.md`) режет
  `tools/slice_sheet.py`, привязка к событиям — `Z.SCENE_RULES` (`engine.js`). Генерировать через Chrome умеет только сессия на Маке.
- Публикация — GitHub Actions `.github/workflows/zhizn-pages.yml` при пуше в `main`:
  https://wrcabeludo-rgb.github.io/games/ — **всегда давать владельцу ссылку.**

## Отложенные идеи (напомнить владельцу)
- **Цвет картинок по счастью** (предложено после 0.5.0): техника рисунка — по возрасту, цвет — по наполненности жизни.
  Серый период — картинка почти обесцвечена (CSS-фильтр), обычная жизнь — как есть, счастье выше 70 — сочнее; для 70–100
  нужны 3 яркие версии сцен (акрил/фломастеры); плавный переход при смене настроения. Владелец думает — напомнено при выпуске 0.6.0,
  ждём решения.
